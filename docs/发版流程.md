# SnipGo 发版流程

> 从 1.1.5 起固定按本流程发版。应用内「检查更新」依赖第 4 步的 GitHub Release，第 2、4 步的约定不能省略。

## 1. 升级版本号

修改 `Resources/Info.plist`：

- `CFBundleShortVersionString`：新版本号，如 `1.1.6`
- `CFBundleVersion`：build 号，在上一版基础上 +1

```bash
/usr/libexec/PlistBuddy -c "Set CFBundleShortVersionString 1.1.6" -c "Set CFBundleVersion 8" Resources/Info.plist
```

## 2. 打包安装包

```bash
./scripts/build.sh            # 不带 --install，不改动本机「应用程序」里的 SnipGo
```

把 `build/SnipGo.app` 重新做 ad-hoc 签名后打成 dmg（dmg 内含 SnipGo.app 和「应用程序」快捷方式）：

```bash
VERSION=1.1.6
STAGE="$(mktemp -d)"
mkdir -p "$STAGE/root"
ditto build/SnipGo.app "$STAGE/root/SnipGo.app"
codesign --force --deep --sign - "$STAGE/root/SnipGo.app"
ln -s /Applications "$STAGE/root/Applications"
hdiutil create -volname SnipGo -srcfolder "$STAGE/root" -ov -format UDZO "Resources/SnipGo-$VERSION.dmg"
git rm Resources/SnipGo-<上一个版本>.dmg   # 仓库里只保留最新安装包
```

打包后清理 build 里的副本，避免程序坞 / Spotlight 指向已删除的应用：

```bash
rm -rf build/SnipGo.app
/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -u "$PWD/build/SnipGo.app"
```

检查安装包：挂载后确认里面有 `SnipGo.app` 和 `Applications`，`codesign -dv` 显示 `Signature=adhoc`，`CFBundleShortVersionString` 是新版本号。

## 3. 提交并推送

分两次提交，推送到 `main`：

1. 功能提交：`feat: …` / `fix: …`（代码、README、`docs/分享文案.md` 等）
2. 发版提交：`release: SnipGo <版本>`（`Resources/Info.plist`、新 dmg、删除旧 dmg）

```bash
git push origin main
```

## 4. 创建 GitHub Release

```bash
gh release create "v$VERSION" "Resources/SnipGo-$VERSION.dmg" \
  -R Conlin-Git/SnipGo --target "$(git rev-parse HEAD)" \
  --title "SnipGo $VERSION" --notes-file <更新说明.md>
```

- 标签必须是 `v<版本号>`，并且附上 dmg。应用内检查更新读取最新 Release，去掉标签前的 `v` 作为版本号，下载附件里的 `.dmg`，并校验 dmg 内应用的版本号与标签一致。
- `--target` 要用完整的提交哈希，短哈希会被 GitHub 拒绝（HTTP 422）。
- 更新说明写清楚改动，并注明：1.1.3 及以后版本可以在应用内「检查更新」，更早的版本需要手动下载安装。

## 5. 发布后核对

```bash
gh api repos/Conlin-Git/SnipGo/releases/latest --jq '{tag_name, assets: [.assets[] | {name, size}]}'
curl -sL -o /dev/null -w "%{http_code} %{size_download}\n" \
  "https://github.com/Conlin-Git/SnipGo/releases/download/v$VERSION/SnipGo-$VERSION.dmg"
```

确认返回新标签，dmg 能下载且大小与本地一致。README 和分享文案的下载链接固定为 `https://github.com/Conlin-Git/SnipGo/releases/latest`，发版时不用改。

## 屏幕录制授权（不要删改）

安装包是 ad-hoc 签名，每个版本的签名都不同。更新后系统里原来的「屏幕与系统录音」授权会失效，表现为系统设置里显示已允许、实际不生效、一直提示需要权限。代码里有两处处理，发版时必须保留：

- `Permissions.checkScreenCaptureOnLaunch()`：新版本第一次启动且没有权限时，先执行 `tccutil reset ScreenCapture local.snipgo.app` 清除旧授权，再重新申请。
- `Updater` 的替换脚本：先等旧版本退出，再清除授权，然后替换应用并重新打开。

用户更新后按提示重新允许一次「屏幕与系统录音」，再重新打开 SnipGo 即可。
