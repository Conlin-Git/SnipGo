# SnipGo 分享文案

> 维护说明：每次新增或调整面向用户的功能、修改快捷键、发布新版本安装包时，同步更新下面的文案（功能列表、快捷键、下载链接中的版本号、安装说明）。

```
分享一个我自己写的 Mac 截图小工具 —— SnipGo ✂️

常驻在菜单栏，按快捷键就能用：
· 截图：拖拽选区，或单击直接选中窗口；多块屏幕也能一起截（⌘A 全选）
· 取色：鼠标移到哪就显示哪的颜色，按 C 复制色值
· 圈图标注：矩形、圆圈、箭头、画笔、文字，颜色和粗细都能换
· 马赛克：涂抹一下就能打码
· 识字 + 翻译：截图里的文字一键识别、翻译，全部在本机离线完成
· 长截图：选好区域后往下滚动页面，自动拼成一张长图
· 钉图：把截图钉在桌面最上层，滚轮就能放大缩小，对照着看很方便
· 录屏：和系统自带录屏一样的操作，可以录整个屏幕或一块区域，导出 mp4

快捷键：⌘⇧1 截图，⌘⇧2 录屏

下载：https://github.com/Conlin-Git/SnipGo/raw/main/Resources/SnipGo-1.1.0.dmg
项目地址：https://github.com/Conlin-Git/SnipGo

安装说明（需要 macOS 15 或更高版本）：
1. 打开 dmg，把 SnipGo 拖进「应用程序」
2. 第一次打开如果提示无法验证开发者，去「系统设置 → 隐私与安全性」，点「仍要打开」
3. 在「隐私与安全性 → 屏幕与系统录音」里允许 SnipGo，然后重新打开它
4. 第一次用翻译时，按系统提示下载语言包即可

有问题或建议欢迎在 GitHub 上提 Issue 🙌
```
