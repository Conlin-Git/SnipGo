# SnipGo 技术方案（自用版）

> macOS 菜单栏截图工具：区域/窗口截图、圈图标注、马赛克、滚动长图、录视频。
> 自用，不上架、不公证；使用本机 Apple Development 证书签名，保证重新编译后系统权限不丢失。

## 2. 技术选型

- **Swift 5 语言模式 + AppKit**（遮罩、选区、工具栏）+ **SwiftUI**（偏好设置）
- **最低 macOS 15**（本机 macOS 26）：可直接用 `SCRecordingOutput` 录屏、`captureMicrophone` 录麦克风
- **ScreenCaptureKit**：`SCScreenshotManager` 冻结屏幕，`SCStream` 采集滚动帧，`SCRecordingOutput` 写 mp4
- **Core Image**：`CIPixellate` 生成马赛克底图
- **Carbon `RegisterEventHotKey`**：全局快捷键（不依赖第三方库）
- **Vision `VNRecognizeTextRequest`**：离线 OCR；**Translation 框架**：离线翻译（SwiftUI `.translationTask`）
- **SMAppService**：开机自启
- **工程**：Swift Package（`SnipCore` 库 + `SnipGo` 可执行 + 单元测试），`scripts/build.sh` 组装 `.app`、生成图标并签名

## 4. 关键实现

### 4.1 截图与选区
1. 触发快捷键后先用 `SCScreenshotManager` 抓取每块屏幕（像素级），同时用 `CGWindowListCopyWindowInfo` 取得按前后顺序排列的窗口矩形（layer 0、非本进程），换算成各屏的 Cocoa 本地坐标。
2. 每块屏幕铺一个无边框遮罩窗口，画冻结图 + 半透明黑色，选区处挖空。
3. 交互：拖拽新建选区；单击选中鼠标下的窗口（空白处选整屏）；8 个手柄调整大小；拖动内部移动；方向键微调（Shift ×10）；尺寸标签显示 `W × H pt`。
4. 导出：在 `选区像素尺寸` 的位图上下文里 `scale(s) + translate(-origin)`，先画冻结图再画标注，保证 Retina 清晰度。
5. 快捷操作：双击 / Enter / ⌘C 复制，⌘S 保存，⌘Z 撤销，⌘A 选中所有屏幕，Esc 取消。
6. 工具栏样式（参考原截图）：选区下方居中的近黑色胶囊条，40pt 按钮、19pt 细线图标、组间短竖线分隔；顺序为 矩形 · 椭圆 · 直线 · 箭头 · 画笔 · 马赛克 · 文字 | 撤销 | 取消(红) · 长截图 · 保存 · 复制；颜色/粗细行同样式置于其下。

### 4.1.1 跨屏选区
- 仍然每块屏幕一个遮罩窗口（「显示器具有单独的空间」开启时窗口无法横跨显示器），但所有屏幕共享一个 `CaptureCanvas`：选区、悬停窗口、标注、当前工具都存全局 Cocoa 坐标。
- 每个 `SelectionView` 用 `setBoundsOrigin(screen.frame.origin)` 把自身坐标系设为全局坐标，绘制、命中测试、工具栏布局直接使用全局坐标；拖拽时鼠标事件持续发给按下时的窗口，坐标超出本屏即为另一块屏幕上的全局坐标。
- 截图模式下选区可在所有屏幕的外接矩形内新建 / 移动 / 调整；单击跨屏窗口可直接选中整个窗口；⌘A 选中所有屏幕。
- 工具栏、钉图按钮只显示在选区底边中点所在的屏幕（否则取重叠面积最大的屏幕），并把该屏窗口设为 key；尺寸标签显示在选区左上角所在的屏幕。
- 导出：按选区涉及屏幕中最高的像素密度建画布，逐屏绘制冻结图（同密度不插值，低分屏放大用平滑插值），再画标注；马赛克底图按屏生成、逐屏裁剪绘制；两块屏幕都不覆盖的区域为透明（jpg 为黑色）。
- 限制：长截图、录屏按显示器采集，选区必须在同一块屏幕内（长截图跨屏时提示；录屏在开始的那块屏幕内选区）。

### 4.1.2 取色器
- 未选区、新建或调整选区时，鼠标右下方显示放大镜：17×17 像素 × 8pt 网格、中心像素框与十字高亮，下方显示坐标（本屏左上角为原点，pt）、色块与颜色值。
- 颜色从冻结图按物理像素取样并转换到 sRGB；按 C 复制颜色并结束截图，按 ⇧ 在 HEX / RGB 间切换（本次运行内记住）。

### 4.2 标注与马赛克
- 模型 `Annotation { tool, color, width, points, text, fontSize }`，屏幕绘制和导出共用 `AnnotationRenderer`。
- 箭头：线段 + 实心三角箭头头部；画笔：中点二次曲线平滑。
- 马赛克：首次使用时对整屏冻结图做 `clampedToExtent → CIPixellate → crop` 得到马赛克底图；涂抹路径 `replacePathWithStrokedPath` 后作为裁剪区域，绘制马赛克底图，屏幕与导出效果一致。
- 文字：点击处放置透明 `NSTextField` 原地编辑，回车或点别处提交为标注。

### 4.3 滚动长图（核心）
**交互**：选区 → 点「长截图」→ 遮罩改为 `ignoresMouseEvents`（鼠标滚轮穿透到下面的应用）→ 用户自己滚动 → 选区右侧白底实时预览（顶部对齐、随长图增长）→ 选区下方居中的图标工具栏：取消 / 钉图 / 保存 / 完成并复制（无提示文字）。

**采帧**：`SCStream`，`sourceRect` = 选区，`showsCursor=false`，30fps（帧间位移越小，重叠越多，越不容易断），`SCContentFilter` 排除本应用所有窗口（遮罩/HUD/预览不会被拍进去）。

**拼接算法**（`SnipCore/ScrollStitcher`）：
1. 每帧每行提取特征：16 个列块的平均亮度 + 行“细节度”（相邻采样点亮度差均值，区分空白行和有内容的行）。
2. 与「上一张被接受的帧」比较：
   - 全部行相同 → 没滚动，丢弃。
   - 首次检测到滚动时锁定**吸顶 T / 吸底 B** 行数：首尾连续相同且含内容的行（各不超过 1/3 高度）。
3. 在中间带 `[T, H-B)` 内枚举位移 dy：当前帧第 i 行 ↔ 上一帧第 i+dy 行，统计不匹配行（超过阈值提前退出）和匹配的「有内容行」数；取不匹配 ≤ 容差且有内容匹配最多的 dy。
4. 重叠区全是空白（无法判断位移）时：当前帧有新内容就取最小可行 dy（压缩空白），否则跳过。
5. 接受后追加当前帧 `[H-B-dy, H-B)` 这段新行（拷贝成独立小图，释放整帧内存），并更新吸底区为当前帧 `[H-B, H)`。
6. 合成：首帧 `[0, H-B)` + 所有新增条带 + 最后的吸底区；高度上限 50000px。
7. 向上滚动 / 滚太快（重叠 < 1/8）时自动忽略该帧，回滚到原位置继续即可。

### 4.4 录视频（QuickTime「新建录屏」风格）
- 按录屏快捷键后直接预选上次（本次运行内记忆）或屏幕中央 60% 的区域，白色虚线框 + 手柄可调整；屏幕底部居中显示毛玻璃控制条：**✕ | 录制整个屏幕 · 录制所选部分 | 选项 ⌄ · 录制**。
- 「选项」菜单：录制麦克风、录制系统声音、显示鼠标指针、存储位置。
- `SCStreamConfiguration`：`sourceRect`、像素宽高取偶数、60fps、`showsCursor`、`capturesAudio`、`captureMicrophone`；`SCRecordingOutput` 直接写 mp4（H.264）。
- 录制中不显示边框和浮窗；菜单栏图标变为「⏹ 计时」，**单击即停止**（再按录屏快捷键也可停止），结束后在 Finder 中定位文件。

### 4.5 钉图
- 截图时选区**右上角外侧**有圆形钉图按钮（右侧放不下时放进选区内右上角），长图工具栏里也有「钉图」按钮：在原位置生成无边框面板，层级为 `screenSaver - 1`（高于所有应用窗口及全屏应用，仅低于截图遮罩），跨所有桌面空间显示。
- 交互：拖动移动；滚轮 / 触控板捏合以鼠标为中心缩放（10%–800%），缩放时显示百分比；`+` / `-` / `0` 放大、缩小、还原；双击或 Esc 关闭；⌘C 复制、⌘S 保存；右键菜单（复制、保存、放大、缩小、实际大小、关闭、关闭所有钉图）。
- 长图钉图时自动缩小到屏幕高度的 90% 以内。

### 4.6 偏好设置
开机自动运行、截图提示音、jpg/png、录屏声音/麦克风/指针、截图与录屏快捷键（录制框下方有设置方法说明；默认 ⌘⇧1 / ⌘⇧2；组合需含 ⌘/⌃/⌥ 之一，F1–F12 可单独使用，Mac 键盘上即 fn+F1…F12）、文件名前缀、保存位置（默认桌面；安装后第一次保存图片时弹窗引导确认或选择保存位置，选择框取消则本次存默认位置、下次再提示；在偏好设置里改过保存位置则不再引导）。布局参考原截图：右对齐标签列 + 左对齐内容列，分组间距 26pt，窗口宽 640pt。窗口顶部为工具栏式标签页：**通用** / **关于**；关于页显示应用图标、版本号、作者（Conlin，GitHub @Conlin-Git）、项目地址（可一键复制）与问题反馈链接。

### 4.8 OCR 与翻译
详细设计见 `docs/OCR与翻译方案.md`。
- 入口：截图工具栏「长截图」之后的「识别文字」(`text.viewfinder`)、「翻译」(`character.bubble`)；识别的是含标注的选区图。
- OCR：Vision `.accurate` + 语言纠正 + 自动检测语言（简/繁中、英、日、韩）；选区像素高度 < 64 时放大 2 倍再识别；`SnipCore/TextLayout` 负责排版：竖向空白带分栏（每栏 ≥3 行且行宽占比 ≥60% 才分，避免拆散表格）→ 纵向重叠 >50% 合并为一行 → 行距明显偏大处分段。
- 翻译：按段落 `reflow`（中日韩直接相连、英文加空格、去行尾连字符）后批量翻译；源语言交给框架自动检测（中英混排时整体判断不可靠），NaturalLanguage 的判断只用于默认目标语言和「原文已是目标语言」提示；翻译前用 `LanguageAvailability` 检查语言对，首次使用由系统弹窗下载语言包。
- 目标语言：上次手动选择的优先（存 `translateTarget`）；原文是中文且上次选的也是中文时用英文；没选过时 中文→英文、其他→简体中文。
- 面板：浮动窗口，放在选区下方（放不下放上方/屏幕中间）；识别模式可点「翻译」切换为左右对照并加宽；Esc / ⌘W 关闭，未选中文字时 ⌘C 复制全部（翻译模式复制译文）；关闭后焦点还给之前的应用。

### 4.7 图标
苹果风白色圆角方块（squircle）+ 居中红色剪刀（源图 `Resources/AppIconSource.png`），`scripts/make_icon.swift` 合成 1024px 后经 `iconutil` 生成 `AppIcon.icns`。菜单栏使用单色剪刀模板图标（SF Symbol `scissors`）。

## 7. 构建与运行
```bash
cd SnipGo && ./scripts/build.sh          # 产物：SnipGo/build/SnipGo.app
open build/SnipGo.app
```
可选 `./scripts/build.sh --install` 安装到 `/Applications`，并删除 `build/` 中的副本、从 LaunchServices 注销，避免启动台出现两个 SnipGo。

安装包：`Resources/SnipGo-<版本>.dmg`（ad-hoc 签名，含「应用程序」快捷方式）。
